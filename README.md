# Labbox ADB Audit

أداة تدقيق محلية بواجهة عربية لفحص أجهزة Android المتصلة عبر ADB وجمع أدلة تشخيصية بموافقة المستخدم.

## مبادئ الأمان

- الفحص للقراءة فقط افتراضيًا؛ لا تنفّذ تغييرات على الجهاز دون موافقة صريحة.
- لا تجمع كلمات مرور أو مفاتيح أو بيانات شخصية غير لازمة.
- اعرض الأوامر المقترحة قبل تنفيذها، وسجّل نتائج الفحص بوضوح.
- تحقّق من المسارات المحلية والبعيدة لمنع تجاوز المجلدات.

## حالة المشروع

هذا المستودع يبدأ بهيكل تأسيسي. ستُضاف الملفات والاختبارات تدريجيًا على الفرع `feature/labbox-adb-audit`، مع إبقاء `main` دون تعديل.

## النطاق الأولي

- اكتشاف أجهزة ADB المتصلة وعرض حالتها.
- فحوصات تشخيصية غير مدمّرة.
- حفظ أدلة محلية مع بصمات تحقق عند الحاجة.
- واجهة عربية واضحة ورسائل أخطاء مفهومة.

## ملاحظة

لا تُعتبر الأداة بديلًا عن تفويض مالك الجهاز. استخدمها فقط على الأجهزة التي تملكها أو لديك إذن صريح بفحصها.
